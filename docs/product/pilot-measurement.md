# 企业试点成效测量方案

> 文档状态：ACTIVE；任务：M14-08a；更新：2026-09-14。
> 测量定义草案；业务阈值、观察周期和参与人员需 O3 确认。本文不包含实际客户效果数据。

## 记录规则

关联 [试点产品包](pilot-package.md)。每次尝试记录匿名参与者 ID、场景/问题 ID、候选 SHA、数据快照、开始结束时间、成功与否、失败阶段、人工协助、结果证据位置。使用 UTC 保存时间，展示时注明时区；不收集原始口令、完整提示词或客户业务明细。

| 指标 | 计算定义 | 防止误读 |
|---|---|---|
| 首个有效结果用时 | 首次开始接入至第一个经业务确认正确结果的总时长 | 另记等待和人工协助时长；失败或未完成者单独列出，不静默剔除 |
| 首次接入成功率 | 首次尝试完成连接→授权→扫描→首问的人数 / 全部开始首次尝试人数 | 分母包含失败者；人工协助成功单列 |
| 任务正确率 | 与事先锁定参考口径及结果一致的有效问题尝试数 / 全部有效问题尝试数 | 系统失败和无结果计入分母；权限负向案例另报通过率 |
| 人工修正次数 | 每次问题尝试的人工改口径、改配置及改查询次数 | 用户正常回答澄清与人工修复分别记录 |
| 重复使用 | 观察周期内至少两个不同日期完成有效任务的人数 / 具备完整观察窗口的参与人数 | 报告观察周期、总人数及未满窗口人数 |
| 节省时间 | 同一类任务人工基线时长减去系统使用及人工协助总时长 | 配对记录；可为负数；不拿不同复杂度任务比较 |
| 支持投入 | 实施及排障人工分钟数 / 参与人数或有效任务数 | 两种分母分别报告 |
| 请求成本 | 可归属的供应商用量乘对应价格版本 | 无供应商凭证时标估算；不把估算写成已核对账单 |

## G1 前需确认

在 O3 记录场景、参考结果确认人、参与者与样本计划、观察周期、各指标成功阈值、数据保存位置和访问负责人。阈值必须先确认再判定；试运行可用于制定阈值，但不能回溯宣布同批数据通过正式验收。

## G1 后执行

M14-08b 收集真实客户数据，输出分母、样本量、周期、失败案例和业务确认结论。样本不足时报告限制，不推断普遍收益。客户效果实测不作为 M14-08a 在 G1 前关闭的前提。

## 关闭条件

上述定义及 O3 决策已确认、记录位置已准备、采集流程完成一次受控演练并可追溯。受控演练不代替客户效果实测。当前 M14-08a 保持 ACTIVE。
