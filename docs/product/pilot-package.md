## 候选验收问题

以下是业务确认清单，不能直接替代 Golden 或写入通过断言。

| 问题 | 需要锁定的口径 | 验证方法 |
|---|---|---|
| 查询入库数量和入库单数量 | 数量字段、计量单位、单据唯一键、有效状态、是否去重 | 在固定数据快照上由业务确认参考查询及结果，再比较两指标；核验关联是否重复累计 |
| 给我最近的十张入库单 | 业务日期字段、时区、相同日期的排序、有效状态 | 比较单据 ID、排序和条数，记录少于十条时的预期 |
| 入库单就是入库凭证（接上问） | 实体别名及允许的澄清答案 | 验证恢复原问题的数量与排序条件，而非开启无关新查询 |
| 将分析成果保存后重新打开 | 试点采用 Dashboard 或 App，以及发布权限 | 比较保存前后数据口径、配置及授权用户访问结果 |
| 无授权用户查询相同数据 | 两个测试租户、数据源授权、RLS 规则 | 应拒绝或只返回明确授权集合；不得将拒绝算成正常业务查询成功 |

原始工程用例参考：[`query-plan-golden-v1.json`](../../SuperBuilder_AI/Evaluation/Golden/query-plan-golden-v1.json)。工程 fixture 的命中字段不能自动视为客户认可的业务口径。

## 数据与证据要求

使用受控测试环境；记录数据快照标识、时间区间、表结构版本、行数、计量单位、状态过滤和脱敏方式。不得将客户明细或凭据直接提交到仓库。

每个问题记录：问题编号、原文、用户角色、权限前提、参考查询位置、参考结果位置、实际结果位置、差异、确认人和确认日期。预期结果在执行前锁定；发现口径错误时保留修订原因并重跑，不覆盖失败记录。

## 试点演示顺序

1. 开通空白租户并登录。
2. 预测试连接，验证预测试不保存数据源；保存后授权、扫描。
3. 确认实体及指标，执行已确认的问题集和权限负向案例。
4. 保存分析成果，刷新、重新登录后打开并核验。
5. 按 [测量方案](pilot-measurement.md) 记录首次接入和使用效果。
