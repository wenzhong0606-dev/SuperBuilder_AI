## 根因

`MetadataScanJob.ProgressDetailsJson` 字段在三处硬编码 `nvarchar(max)` 类型：

1. `src/Infrastructure/Persistence/SuperBIContext.cs`（OnModelCreating）
2. `src/Infrastructure/Persistence/Migrations/SuperBIContextModelSnapshot.cs`（BuildModel）
3. `src/Infrastructure/Persistence/Migrations/20260914062000_M13_MetadataScanRichProgress.cs`（Up）

单元测试工程使用 **in-memory SQLite**。SQLite 解析 `nvarchar(max)` 的 `(max)` 语法报错：

```
Microsoft.Data.Sqlite.SqliteException : SQLite Error 1: 'near "max": syntax error'.
```

所有基于 `SuperBIContext` 的 SQLite 测试类在 schema 初始化（`EnsureCreated` 或迁移重放）阶段同时崩溃
（AgentRuntimeTests / TenantLanguageServiceTests / M2_01_PlatformAdminTests /
QueryPlanSecurityGateTests 等），故表现为「一大片同时红」而非单个用例。

`Stage` 字段仅用 `HasMaxLength(64)`（无 `HasColumnType`），SQLite 接受 `nvarchar(64)`，**不是**问题来源。

## 修复（三处一致去掉 `nvarchar(max)`）

**A. SuperBIContext.cs**
```csharp
// 改前
builder.Entity<MetadataScanJob>().Property(x => x.ProgressDetailsJson)
    .HasColumnType("nvarchar(max)").HasComment("扫描富进度快照(JSON)");
// 改后（去掉 HasColumnType，让 provider 自选 TEXT / nvarchar(max)）
builder.Entity<MetadataScanJob>().Property(x => x.ProgressDetailsJson)
    .HasComment("扫描富进度快照(JSON)");
```

**B. SuperBIContextModelSnapshot.cs**
```csharp
// 删除这一行里的 .HasColumnType("nvarchar(max)")
b.Property<string>("ProgressDetailsJson")
    .HasComment("扫描富进度快照(JSON)");
```

**C. 迁移 20260914062000_M13_MetadataScanRichProgress.cs — Up()**
```csharp
migrationBuilder.AddColumn<string>(
    name: "ProgressDetailsJson",
    table: "MetadataScanJobs",
    // 删除 type: "nvarchar(max)"
    nullable: true,
    comment: "扫描富进度快照(JSON)");
```

> 迁移 id / `schema-version.json` 不变，`Stage`/`Down()` 不动。三处去掉 `type` 后 EF 默认
> SQL Server → `nvarchar(max)`、SQLite → `TEXT`，跨 provider 兼容，模型与快照一致。

### 根因

- `Stage` (nvarchar(64), not null, default 'Queued')

`POST /api/data-sources/{id}/metadata/scan` 在 `_db.SaveChangesAsync()` 写入 `MetadataScanJobs` 时，SQL Server 报 `Invalid column name 'ProgressDetailsJson'`，未被全局异常处理捕获 → 返回 HTTP 500 → 前端显示"服务暂时不可用"。

### 验证

在真实元库执行：

```sql
SELECT name FROM sys.columns
WHERE object_id = OBJECT_ID('MetadataScanJobs')
  AND name IN ('ProgressDetailsJson','Stage');

SELECT MigrationId FROM __EFMigrationsHistory
WHERE MigrationId = '20260914062000_M13_MetadataScanRichProgress';
```

若列缺、或迁移历史缺，即确认本根因。

  --project SuperBuilder_AI/SuperBuilder_AI.csproj \

  --configuration Release

确保连接串指向真实元库，执行后重启 API。
