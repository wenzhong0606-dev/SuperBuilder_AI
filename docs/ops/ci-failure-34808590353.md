## 根因

`MetadataScanJob.ProgressDetailsJson` 字段在三处硬编码 `nvarchar(max)` 类型：

1. `src/Infrastructure/Persistence/SuperBIContext.cs`（OnModelCreating）
2. `src/Infrastructure/Persistence/Migrations/SuperBIContextModelSnapshot.cs`（BuildModel）
3. `src/Infrastructure/Persistence/Migrations/20260914062000_M13_MetadataScanRichProgress.cs`（Up）

单元测试工程使用 **in-memory SQLite**。SQLite 解析 `nvarchar(max)` 的 `(max)` 语法报错：

```
Microsoft.Data.Sqlite.SqliteException : SQLite Error 1: 'near "max": syntax error'.
```

所有基于 `SuperBIContext` 的 SQLite 测试类在 schema 初始化（`EnsureCreated` 或迁移重放）阶段同时崩溃
（AgentRuntimeTests / TenantLanguageServiceTests / M2_01_PlatformAdminTests /
QueryPlanSecurityGateTests 等），故表现为「一大片同时红」而非单个用例。

`Stage` 字段仅用 `HasMaxLength(64)`（无 `HasColumnType`），SQLite 接受 `nvarchar(64)`，**不是**问题来源。

## 修复（三处一致去掉 `nvarchar(max)`）

**A. SuperBIContext.cs**

    .HasColumnType("nvarchar(max)").HasComment("扫描富进度快照(JSON)");
// 改后（去掉 HasColumnType，让 provider 自选 TEXT / nvarchar(max)）
builder.Entity<MetadataScanJob>().Property(x => x.ProgressDetailsJson)
