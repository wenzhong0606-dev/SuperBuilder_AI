# M14 — 商业化交付、权益与经营闭环

> 基线：2026-09-12，git 69db2fc。对应用户要求将产品化/商业化分析转成开发任务。
> 状态：待执行。与 M13 联动；44% 商业化估分不是收入预测或验收标准。
> 默认先支持有人服务的企业试点/项目交付，订阅支付为自助 SaaS 的条件项。本文不选择支付供应商、不设定价格、不代替合同或合规审查。

## M14-01 — 试点产品包与验收数据集（P1；产品/实施）
- 依赖：M13-01。
- 工作：从现有库存/入库等已验证场景选择一个试点场景，定义目标用户、业务问题、数据要求、已支持/未支持能力、实施边界和验收问题集；由产品负责人确认后锁定，未确认只作为候选。
- 交付：docs/product/pilot-package.md、版本化验收数据及问题清单、演示步骤。
- 验收：每个问题有经业务确认的参考口径/结果、数据来源、权限条件；至少完成一个从接入到保存分析成果的真实案例；错误结果如何反馈明确。不得把开发自测当客户效果。

## M14-02 — 套餐权益与租户授权（P1；后端/产品）
- 依赖：01、M13-02。
- 工作：定义版本化套餐、租户生效期和权益映射，绑定已有配额；支持试用/正式/到期/暂停状态及管理员调整审计，价格保留配置。
- 落点：QuotaPolicy、QuotaController、租户管理页；新增实体/迁移/API/UI按既有架构归档。
- 验收：到期/超限在服务端强制，不能靠隐藏按钮；变更幂等并记录生效时间；不得影响其他租户；到期后保留数据导出/交接策略，不直接删数据。

## M14-03 — 业务路径配额强制与并发一致性（P1；后端）
- 依赖：02、M13-02。
- 工作：梳理用户、数据源、App、Agent、Dashboard 创建及 API 调用路径，接入服务端检查与原子消费；处理失败释放、删除释放、周期重置和重试幂等。
- 落点：QuotaService/IQuotaService、相关写服务和请求计量入口。
- 验收：并发争抢最后一份额度最多一份成功；失败事务不耗额度；重试不重复计数；读配额不创建用量；边界按统一 UTC 周期验证；直接 API 请求无法绕过。

## M14-04 — 用量账本与 AI 成本归集（P1；后端/运营）
- 依赖：03、M13-11。
- 工作：记录租户/用户/操作/请求关联 ID、模型/供应商、输入输出 token、缓存命中、耗时、成功/失败、价格版本；无实际供应商用量时标为估算，成本与对客售价分离。
- 交付：可追溯用量账本、租户用量页、成本报表和脱敏导出。
- 验收：以一组真实请求核对供应商用量；重试/流式中断不重复记账；跨月价格变化可追溯；租户只能看自身用量；不将提示词/业务明细默认写入账本。

## M14-05 — 项目制收费与交付台账（P1；产品/运营，开发配合）
- 依赖：01、02、04，实际收费前须 M13 G1。
- 工作：建立客户、合同引用、交付版本、授权周期、验收记录、应收/已收、发票状态、续费提醒的管理流程；可以先用受控台账，明确哪些字段随后产品化，不强制先造支付系统。
- 验收：模拟一个客户从开通到验收、对账、续期、退出的全周期；合同约定能力与实际权益一致；支持费用和实际用量可归集到客户。真实签约、收款、开票由获授权人员处理。

## M14-06 — 自助订阅、支付回调及对账（P2；仅自助 SaaS 必需）
- 依赖：02~05，支付渠道与商品规则须先确认。
- 工作：订单、订阅、支付状态机、退款/取消、签名校验、回调幂等、对账、欠费宽限和恢复；不在浏览器成功页直接开权益。
- 验收：在供应商沙箱验证重复/乱序/伪造回调、金额或币种不符、超时、退款、续订、取消；权益按已确认支付结果准确变更；账单与账本可核对。未选渠道时状态为待决策，不假定已经集成。

## M14-07 — 支持与客户交接包（P1；运维/实施/产品）
- 依赖：01、M13-10/11/14（先写手册，门禁通过后定稿）。
- 工作：安装升级指南、客户配置清单、故障级别和处理责任、备份恢复说明、支持入口、数据导出/退出流程；服务目标依据 M13-10/12 实测设定。
- 验收：非开发人员按指南完成安装与一次升级；测试故障能按关联 ID 定位；退出可导出约定数据，数据保留与删除流程明确且有授权记录；服务承诺不超过实测能力。

## M14-08 — 试点成效与续用评估（P1；产品/客户成功）
- 依赖：01；采集方案先完成，真实客户测量在 M13 G1 后。
- 工作：定义首个有效结果用时、首次接入成功率、任务正确率、人工修正次数、周活跃/重复使用、节省时间、支持投入、实际成本及付费意愿的采集办法。
- 验收：试点前记录基线和成功阈值；试点后附完整分母、样本量、周期和失败案例；业务负责人确认收益；输出继续投入/缩小范围/停止的结论。没有真实客户数据时保持待验收，不使用模拟数据替代。
