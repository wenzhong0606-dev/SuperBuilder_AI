## 1. 目标、范围与发布门槛

第一阶段交付目标：可重复部署、有人支持的企业 Web 试点。先使用现有 SQL Server/MySQL/PostgreSQL 能力和明确场景；移动端、全连接器、全模型不是本阶段强制承诺。若对客户销售这些能力，相应验证立即成为发布门禁。

- G0 内部候选版：M13-01~07 通过。鉴权越权、密钥明文写入、缺表启动、核心评估失败均不能以其他任务已完成抵消。
- G1 外部企业试点：G0 + M13-09~12、14、16 + M14-01、07、08 的交付物就绪。M13-08 未完成的 Agent 能力按 M13-07 禁用，不得对外承诺。
- G2 可复用商业交付：G1 + M14-02~05；通过客户验收并有成本/支持记录。自助 SaaS 额外要求 M14-06。
- 条件门禁：客户需要列权限自助管理或自定义组件时，分别加 M13-13 / 15；SSO、多模型、其他数据库沿用 M10 编号另排期。
