# .workbuddy Governance

> Status: ARCHIVED / TOOLING CONTEXT

`.workbuddy/` 保存历史工作记忆、审计快照和工具技能。它不是项目当前事实来源。

发生冲突时：

1. 当前源码/测试；
2. `docs/Master_Development_Plan.md`；
3. `docs/milestones/`；
4. `docs/plans/active/`；
5. `docs/Development_Backlog.md`；
6. 最后才参考 `.workbuddy/`。

`.workbuddy/memory/` 只用于恢复历史上下文；`.workbuddy/audits/` 只表示审计当天的状态，不能当作当前缺陷清单。
