### D17 修复（GQ-002 EntityCount 聚合漂移）
- 根因：LLM intent 把"查询入库单数量"生成为 SUM(id)；`QueryPlanMetricScoringService.EvaluateMetric` 严格断言 expected=Count vs actual=Sum → 0 分。
- 修复（MetricType 传播链，5 处最小修改）：
  1. `SemanticApplicabilityMetricResolution` 增加 `MetricType` 字段（默认 ColumnMetric）
  2. `SemanticApplicabilityEvaluator.EvaluateAsync` 填 `MetricType = result.MetricType`（来源：Golden Aggregation==Count → EntityCount）
  3. `QueryPlanMetricResolution` 增加 `MetricType` 字段
  4. `QueryPlanSemanticResolutionFactory.From` 透传 MetricType（含 fallback 分支）
  5. `QueryPlanBuilder.ApplyMetricResolutions`：`MetricType == "EntityCount"` 时强制 `plan.Metrics[i].Aggregation = "COUNT"`（覆盖 LLM 猜测，不放宽评分器）
- 附带修复：2 参 BuildAsync 从未给 `plan.DataSourceId` 赋值（1 参路径在 QueryPlanBuilder.cs:744 有，2 参遗漏）→ 在 NormalizeJoinSemantics 后从 plan.Tables 回填，修复 `dataSourceBindingMatchesResolution=false`。
