## M12-P0 权限矩阵 CI 实跑根因定位与修复

目标：让 `PermissionMatrixE2ETests`（17 用例）在 CI 真实执行并全绿。

### 现象（CI run 34566854796）
- 17 总数 / 5 通过 / 12 失败。
- 经 GitHub REST API 拉取 E2E job 日志（`actions/jobs/103160847608/logs`）分析。

### 根因
1. **登录 429（主因，12 例全因此失败）**
   - `RateLimitMiddleware` 默认 `LoginLimit=10`/`LoginWindowSeconds=60`（见 `RateLimitOptions.cs`）。
   - CI 无 gitignored `appsettings.Local.json`（本地 LoginLimit=500/GlobalLimit=1000），回退默认。
   - 限流键：登录路径以 `ip:{RemoteIp}+{UA 哈希}` 为键；所有 E2E 登录来自 `127.0.0.1` 同一 Playwright UA → 共用一个桶。
   - 矩阵 ~19 次登录在 60s 窗口内触顶 10 → 其余用例 `SB_TOO_MANY_REQUESTS`(429)。
   - 证据：日志 `Microsoft.Playwright.PlaywrightException : Error: login 429 {"Code":"SB_TOO_MANY_REQUESTS"...}`。

2. **`ThemeEditor` 调色板 `KeyNotFoundException 'primary'`（次因，admin `/themes` 必崩）**
   - `_tokens` 初值空字典，仅 `InitTokensFromNode` 填充；`OnAfterRenderAsync(firstRender)` 在会话自举前触发 → `api/themes/editor/blueprint` 以 `authTenant=0` 匿名发出（日志 REQ ... authTenant=0）→ 401 → catch → `_tokens` 仍空 → 渲染 `_tokens[key]` 抛 `KeyNotFoundException`。
   - 证据：日志 `Unhandled exception rendering component: The given key 'primary' was not present in the dictionary.` @ `ThemeEditor.razor:96`。

### 修复
- `.github/workflows/dotnet-build.yml`「启动 Web API」步骤注入 `RateLimit__LoginLimit=500`/`RateLimit__GlobalLimit=1000`（仅 CI）。
- `ThemeEditor.razor`：`_tokens` 防御性初始化 `TokenOrder.ToDictionary(k=>k,"")`；仿 `AppPreview`/`AppRun` 在 `OnInitialized` 订阅 `State.SessionRestoredChanged`、`OnAfterRenderAsync` 仅 `State.SessionRestored` 后取数；加 `@implements IDisposable`+`Dispose`。
- Components 工程 `dotnet build -p:TargetFrameworks=net10.0 --no-restore` 0 错（沙箱内 `dotnet restore` 因 `ProgramData` 不可解析失败，属环境限制，CI 不受影响）。
