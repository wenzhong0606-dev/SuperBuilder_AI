## 新增踩坑（Blazor）
- 事件处理器内联 `Nav.NavigateTo("x")` 必须用**单引号**定界属性：`@onclick='() => Nav.NavigateTo("ask")'`；双引号版会提前闭合属性 → 生成代码 CS1026（9 处批量修正）。
- `<details>` 不支持 `@bind-open`（RZ9991），只能用普通属性。
- 页面登录判定必须等 `AppState.SessionRestored`（子组件 OnAfterRender 早于 MainLayout 的会话自举），否则预渲染/首帧误判未登录。
- 并行 `dotnet build` 同一解决方案会因 bin 文件被重建删除而报 MSB3030，串行执行。

### S1 新增踩坑
- `SbListPage` ErrorState `Message="@Error!"` → RZ9986（组件属性不支持混合 C#/标记），改 `@(Error ?? string.Empty)`。
- `SbStatTile Value` 是 `object` 类型，`Value="—"` 被当 C# 负号表达式（CS1525）→ 用 `@("-")` 强制字符串字面量；`Value="@_rows.Count"`（int→object）正常。

- `PermissionGuard.Require` 为 `IReadOnlyList<string>`，示例须 `Require="@(new[]{"demo:write"})"`，勿传单字符串。
- 子组件 `AskTurnCard` 内修改 `turn.Overrides` 后无需手动 `StateHasChanged`：按钮点击事件由该组件处理，Blazor 自动重渲染；父页共享同一 `Turn` 实例，DoRefine/Publish 经 `EventCallback` 回父页修改后父重渲染、子随参重渲染。

### S2 踩坑
- `SbConfirm`/`SbModal` 必须放在 `SbListPage` **之外**（同 AuthGuard 内），否则 RZ9996「Unrecognized child content」。

### S2 补全（租户设置 Upsert / 字段级校验）
- 租户设置：`POST api/tenant-management/{id:long}/settings`（`UpsertTenantSettingRequest{Key,Value,DataType}`）真实存在，已接入 `Tenants.razor`「设置」模态（GET 现有 → 列表 + 新增/更新一条）。
- 后端写操作错误体为扁平 `{ errors:["..."] }` 数组（非字段字典）。`ApiClient.ParseApiError` 原先不识别，回退为截断原始 JSON 文本；已补 `errors` 数组分支（逐条 join「；」），所有写操作失败提示友好化。
- 字段级校验走前端：`SbField Required` + `Error` 参数，提交前置校验未填/格式错写入对应字段（Tenants/SemanticLabels/Identity）。后端不返回字段名，故服务端错误仍聚合成表单级提示——S2-6 验收定为「客户端字段级 + 服务端错误可读化」。
- Razor 踩坑：`GetJsonAsync` 返回的 `data` 是 `JsonElement?`，模式匹配 `is { ValueKind: Array }` 后仍须 `.Value.EnumerateArray()`（不能直接 `data.EnumerateArray()`，CS1061）。
- `ApiClient.ParseApiError` 内 `foreach` 变量名勿与上层 `var e = Deserialize<ApiError>(...)` 冲突（CS0136），已改名 `item`。
