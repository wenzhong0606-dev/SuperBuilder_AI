### 踩坑（已付学费，务必遵守）
1. **事件处理器含 C# 字符串 → 属性须用单引号定界**：`@onclick='() => Toast("文本")'` ✅；`@onclick="() => Toast('文本')"` ❌（内部单引号被当 char 字面量 → CS1012「字符字面量中的字符太多」）；`$"..."` 内嵌双引号会提前闭合属性 → CS1056/CS1026。
2. **渲染名为 `code` 的变量必须写 `@(code)`**：`<span>@code</span>` 被 Razor 当作 `@code` 指令 → RZ2005/RZ1017（Apps.razor 踩到）。
3. **void 方法不能直接绑 `@onclick='Toast("x")'`** → CS1503（void 无法转 EventCallback），须包 lambda `'() => Toast("x")'`。
4. **DI：页面只能注入 `IApiClient`**（注册为 `AddScoped<IApiClient, ApiClient>()`），注入具体类 `Services.ApiClient` → 运行时 500「无注册服务」。**给 ApiClient 加新方法必须同步加到 `IApiClient` 接口**，否则改回接口注入后编译不过（本轮 `GetJsonAsync` 即此坑，9 个页面 500）。
5. 元组取值：命名字段元组 `(string Label, string Light, string Dark)` 无 `.Value`，直接 `.Light`/`.Dark`（Themes.razor 踩到 CS1061）。
6. `record` 位置属性是 init-only，无法事后赋值 `m.Default = ...` → CS8852；需可变状态改用 `class`（ModelAccounts.razor 踩到）。
